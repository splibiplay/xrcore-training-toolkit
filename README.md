Guided training runtime layer for XRCore in Unity XR.

## GitHub policy

This repository is maintained as **documentation + distribution metadata**.
Runtime implementation is delivered through Unity package distribution.

## Published foundation (Unity Asset Store)

Install XRCore foundation first:

- [XRCore - Event-Driven AI Framework for Unity XR](https://assetstore.unity.com/packages/tools/ai-ml-integration/xrcore-event-driven-ai-framework-for-unity-xr-366852)

## Value in 2 Minutes

1. Install XRCore SDK + Training Toolkit.
2. Open the training sample scene.
3. Run `Look -> Grab -> Place`.
4. Validate scenario progression and feedback.

## What this module adds

- scenario orchestration (`XRTrainingScenario`, `XRTrainingStep`)
- progression runtime (`XRTrainingScenarioRunner`)
- validator-driven completion logic
- training UX feedback surfaces
