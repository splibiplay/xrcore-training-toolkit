The guided training runtime layer of XRCore for Unity XR.

## Published foundation (Unity Asset Store)

Install the core SDK from Unity first, then add this module via Git URL:

- [XRCore – Event-Driven AI Framework for Unity XR](https://assetstore.unity.com/packages/tools/ai-ml-integration/xrcore-event-driven-ai-framework-for-unity-xr-366852)

## Value in 2 Minutes

1. Install XRCore SDK + Training Toolkit.
2. Open the sample training scene.
3. Run `Look -> Grab -> Place`.
4. Confirm validator-driven progression and feedback.

## What It Adds

On top of XRCore SDK, Toolkit delivers:
- scenario orchestration (`XRTrainingScenario`, `XRTrainingStep`)
- progression runner (`XRTrainingScenarioRunner`)
- modular validators and fail conditions
- training UX feedback (instructions, highlights, progress)
